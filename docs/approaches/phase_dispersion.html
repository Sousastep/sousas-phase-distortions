How Disburser Uses Allpass Filters to Make Its Sound

Why a long chain of allpass filters produces this effect's characteristic sound — and why a cascade of identical stages is the whole trick.

This note explains the DSP behind this reverse-engineered Kilohearts Disperser clone (Disburser) and, in particular, why a long chain of allpass filters is what produces the effect's characteristic sound.

The entire effect lives in Source/PluginProcessor.cpp, in processBlock(), and it is surprisingly small. Everything interesting is one idea executed well:

Run the signal through up to 32 identical, second-order allpass filters in series,
with a shared cutoff and resonance, and use the phase distortion that accumulates
to smear transients in time without changing the frequency balance.

1  The One Structural Fact That Matters

std::array<juce::dsp::IIR::Filter<float>, 64> allpasses; // PluginProcessor.h

auto coef = juce::dsp::IIR::Coefficients<float>::makeAllPass(
                 getSampleRate(), cutoff->get(), smash->get());   // one coefficient set

for (int filter = 0; filter < scatterValue; filter += 2)
{
    if (s % 100 == 0)
    {
        allpass[filter].coefficients     = coef;   // even indices  -> left
        allpass[filter + 1].coefficients = coef;   // odd  indices  -> right
    }
    left  = allpass[filter].processSample(left);
    right = allpass[filter + 1].processSample(right);
}

Three things stand out:

  1. One coefficient set is shared by every filter. All stages are identical makeAllPass(sampleRate, cutoff, smash) biquads. cutoff and smash are the same for the whole chain; only the number of stages (scatter) changes.
  2. The chain is pure feed-forward series. The output of stage n is the input of stage n+1, and there is no dry/wet mix. That is the crucial difference from a phaser (see §5).
  3. Even/odd indices are just a stereo split. Indices 0, 2, 4, … process the left channel and 1, 3, 5, … the right, so the "64 filters" are really 32 allpass stages per channel, with scatter counting stages in an interleaved layout.

makeAllPass builds a second-order (biquad) allpass with transfer function

        a2 + a1·z⁻¹ + z⁻²
H(z) = ─────────────────────
        1  + a1·z⁻¹ + a2·z⁻²

Its coefficients are set by the corner frequency (the Cutoff parameter) and Q (the Smash parameter).

2  What an Allpass Filter Actually Does

The defining property of an allpass filter is that its magnitude response is exactly flat at every frequency — |H(e^{jω})| = 1 — while its phase response is not.

So a single allpass leaves the "EQ" of the sound completely untouched: every frequency keeps the same amplitude. What it changes is the timing of each frequency, and timing is described by group delay:

group delay τ(ω) = -dφ(ω)/dω

An allpass introduces a frequency-dependent delay. A biquad allpass centered on the Cutoff frequency delays components around that frequency more than components far from it. Raising Q (i.e. Smash) makes that band of extra delay taller and narrower — a sharp spike of group delay at the cutoff. Lowering Q spreads a milder, broader delay bump across the spectrum.

This is the whole trick: an allpass is a tone-shaping reverb-tail generator that never touches the tone.

3  Why Cascading Is the Effect

Phase responses add when filters are placed in series, so the total phase of a chain of N identical allpasses is N · φ(ω). Group delay is linear in phase, so:

τ_total(ω) = N · τ_single(ω)

Cascading multiplies the group delay by the number of stages. With scatter up to 64 (32 stages per channel), the group delay around the cutoff becomes tens or hundreds of times larger than a single stage would give — a genuinely large, frequency-selective time smearing.

What That Does to a Transient

A transient (a click, a kick drum attack, a pluck) is broadband: it contains energy at all frequencies at once. Send it through the chain and each frequency band gets delayed by a different amount:

  • frequencies near Cutoff are held back the most,
  • frequencies away from Cutoff pass nearly on time.

The impulse is therefore unfolded in time into a smeared, chirp-like tail — the energy spreads out over time instead of staying packed into a sharp spike. That stretching of transients, while the spectrum's magnitudes stay put, is exactly what makes a "disperser" sound like a disperser rather than an EQ or a reverb. It is also literally what the word means physically: in a dispersive medium, waves of different frequencies travel at different speeds, so a sharp pulse spreads into a chirp.

Because the magnitude response stays flat, the change is often described as "the sound gets fatter / squishier / more liquid" while "the tone stays the same."

4  What Each Knob Controls

Parameter Code Role
Scatter scatterValue, range 0–64 step 2 Number of allpass stages in the cascade (2 stages per increment). Zero = bypass; higher = more accumulated phase/group delay = more smearing.
Cutoff cutoff->get(), 20 Hz–20 kHz, default 200 Hz The allpass corner frequency — where the group-delay bump is centered, i.e. which part of the spectrum gets delayed the most.
Smash smash->get(), 0.71–10 The allpass Q (resonance). Higher = sharper, taller group-delay spike at the cutoff = a more pronounced, more "resonant" smear.

At the default Smash = 0.71 (a maximally-flat / Butterworth-like Q) the chain is clean and smooth; pushing Smash up narrows the affected band into an aggressive resonant smear.

Practical Mapping

  • More Scatter → longer, more obvious dispersion, more pre-ringing before transients.
  • Low Cutoff → the low end / body of the sound smears; kicks get bloated or bounce.
  • High Cutoff → the hi-hats / air / attack smear; transient edges go soft or metallic.
  • High Smash → the smearing concentrates into a narrow band and rings, adding a pitched, resonant quality on top of the dispersion.

5  Why This Is Not a Phaser

A classic phaser uses the same allpass chain, but then sums it with the dry signal. That dry/wet sum interferes frequency-selectively and carves the familiar notches that sweep across the spectrum — a magnitude effect.

This plugin never mixes the dry signal back in. It is a pure series cascade, so no interference notches exist and the magnitude response stays flat. What remains — and what you hear — is only the time dispersion. Same building block, different signal flow, completely different effect.

It is also worth noting the feed-forward, static coefficients mean this is a memoryless-in-the-long-run chain with no feedback loop. There is no delay line and no echo: the smearing comes purely from the phase of the filters, not from recirculated audio.

6  Implementation Details That Affect the Sound

Coefficient Update Rate (Anti-Zipper)

if (s % 100 == 0)
{
    allpass[filter].coefficients     = coef;
    allpass[filter + 1].coefficients = coef;
}

New coefficients are only pushed into the filters every 100 samples rather than every sample. This quantizes parameter changes and avoids zipper noise / per-sample coefficient churn. Between updates the filters keep the previous coefficients.

Parameter-Change Gate (Anti-Popping)

scatterValues.push_back(scatterValue);          // keep the last 60 values
if (scatterValues.size() > 60) scatterValues.erase(scatterValues.begin());

auto scatterSize = scatterValues.size();
for (int i = 0; i < scatterSize; i++) avgValue += scatterValues[i];

if ((avgValue / scatterSize) == scatterValue)   // only process when settled

scatter is a std::vector<int>, so pushing a float truncates it to an integer, and avgValue is an int. The effect only runs the filter chain on a block when the integer average of the last 60 scatter values equals the current scatter value — that is, when the knob has been still long enough that the recent history is all the same value. While Scatter is being moved, avgValue / scatterSize lags behind and the block is skipped, preventing the loud clicks that reconfiguring a long filter cascade would otherwise cause. It is a crude but effective "has the user stopped turning the knob yet?" debounce.

(The coefficient update also sits inside the per-filter loop and recomputes coef once per block outside the sample loop; both are harmless redundancies.)

7  One-Paragraph Summary

Disburser is a cascade of up to 32 identical second-order allpass biquads per channel. An allpass is flat in magnitude but frequency-dependent in phase, so it delays different frequencies by different amounts without changing the timbre. Stacking many identical stages multiplies that phase by the number of stages, blowing up the group-delay spike near the allpass corner frequency into a large, frequency-selective time smear. Passing broadband transients through this unpacked-in-time delay stretches them into chirp-like tails while the magnitude spectrum — and therefore the perceived tone — stays intact. Scatter chooses how many stages (how much dispersion), Cutoff chooses where in the spectrum it happens, and Smash sets the Q (how sharp and resonant the delay peak is). Because there is no dry/wet sum and no feedback, you get pure time dispersion rather than the notched magnitude coloration of a phaser.
